# Security

EdgeBench Verified is an independent project and is not affiliated with ByteDance or EdgeBench's
authors.

- **Problems in this repository**, such as the fix packages, scripts or website: please open a GitHub
  issue. If the problem should not be public, contact the repository owner privately first.
- **Problems in EdgeBench itself**, such as its grading software or images: please report them to
  EdgeBench's maintainers through the channels in the
  [EdgeBench repository](https://github.com/ByteDance-Seed/EdgeBench).
