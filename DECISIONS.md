# Outcome for every task

The same data for all 51 public tasks is in [data/decisions.csv](data/decisions.csv), whose `decision` column uses the codes `retain-with-note`, `repair-v2` (fixed) and `exclude` (removed).

| Outcome | Tasks | Meaning |
| --- | ---: | --- |
| Fixed | 31 | A problem that changes scores, with a versioned repair package. This outcome is historical and does not certify every current release; APPLYING-FIXES.md and each case page give the component coverage and the integration still pending. |
| Removed | 1 | A problem without a sound fix; the task is not part of the verified set. |
| Kept, with a note | 19 | No correctable problem found. The note records caveats that no change to the grader removes, including run-to-run or machine-dependent variation, with its size stated or marked unmeasured. Some are not small; the largest, in ANN Vector Search, is about ±7 of 100 points per grading. |
