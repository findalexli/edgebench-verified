Every public EdgeBench task has its own page. Each shows the instructions the agent receives, how EdgeBench grades the work, and what we found: the test submissions, the independent checks and, for a fixed task, the fix. Select any task to open it.

Fixed: a past decision to repair the task, with a versioned package and evidence for that task. It does not certify every current release. Native, component and integration limits are listed on each task page and in the package status. Kept, with a note: no correctable problem; caveats such as run-to-run variation are recorded. Removed: no sound fix was possible. Problem category: each fixed or removed task has one primary category, set by the mechanism of its main defect, and may have secondary ones; the second row of buttons filters by the primary category.
