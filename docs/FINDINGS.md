# What we found

These twelve conclusions describe specific, confirmed problems in the acquired task versions. They do not certify whole tasks or show how often each problem affects benchmark scores. Current task decisions are on [the status page](../AUDIT-STATUS.md).

“Original check run” below means an actual original task component ran. It does not imply that the entire hosted benchmark ran. Local replays and mathematical arguments are labelled separately.

| Task | Confirmed problem | How it was checked | What the evidence does not establish |
| --- | --- | --- | --- |
| Triangulation Coloring | All ten acquired large meshes contain overlapping triangle interiors, violating the promised input structure. | Acquired-data geometry checks and original task execution. | Why the bad meshes were generated, or whether future meshes are valid. |
| Equivalence Classes | One original checker accepts output whose operation cost exceeds its stated limit. | Original check run with an at-limit control and an above-limit example. | A score gain. Other runs still encountered submission errors. |
| Graph Node Classification | The original checker silently turns NaN into zero, then accepts the complete submission despite the required confidence range of zero to one. | Original validation run; the complete result was accepted and selected. | Score inflation, or an explicit rule requiring zero credit or rejection. |
| Schemathesis Config | The required identity check is missing, so metric tests accept a wrapper instead of the identical decorated function. | Original component tests and recovered complete original scoring of reference and wrapper. | A wrapper score gain or actual history selection. Both received the same partial score; the task decision remains pending. |
| Tree Block Partitioning | A multiplication routine gives the wrong answer when an input and output refer to the same object. | Original routine checked against the specified polynomial meaning on six selected cases. | Correctness of all other operations or freedom from overflow. |
| Lean Analysis Proofs | Two requested statements are false under their written assumptions and intended mathematical meanings. | Source inspection and mathematical counterexamples, separately reviewed. | An installed Lean compiler result. Partial credit remains possible. |
| SMT Solver | The recovered witness lookup merges expressions from different variable scopes, so it cannot represent the distinct values needed in a constructed satisfiable case. | Source analysis and a small constructed test. | An actual full-image failure, false acceptance or score effect. Further implementation work is held. |
| FFmpeg Scaling | A recovered timing component can report a positive speed ratio for an error or missing output without checking those timed results. | Local replay with controlled substitutes. | Bypassing the task's separate correctness checks or improving real performance. Further implementation work is held. |
| College English Exam | Grading can be marked complete without every required rule being assessed. The earlier grader copy returned 100 for empty or incomplete assessments. | Independent final-source inspection and four offline final-source original/candidate calls with fixed responses. | A final 100-point result, live provider incidence, installed-image parity, educational correctness or certification of the replacement. |
| Order Addition | The original integrity test rejects its own installed scoring helper because the expected and actual hashes differ. | Original tests and matched valid/invalid controls for a small correction. | Approval of the corrected task for release. Valid original scores are still possible. |
| Jagua Nesting | The original placement validator accepts selected shapes whose interiors overlap. | Original complete placement validator on retained and installed overlapping examples, with contrasting controls. | A score gain or a complete geometry repair. Five equal-width cases gave zero improvement; three other overlap cases rejected. |
| Wireless Electricity Layout | The raw scoring path ranks an observed compilation failure above an observed feasible solution. | Original grading components plus review of the final selection rule. | A normalized leaderboard gain: all three observed normalized scores were zero. |

Graph’s original version remains excluded because the task requires numerical confidences in `[0, 1]`, while the checker silently replaces an undefined supplied value and still accepts the complete result. The decision concerns whether the output meets the task’s requirements. The evidence does not show score inflation or an explicit rule requiring zero credit or rejection for every confidence violation. Excluding the original does not approve a corrected version. [Qualification review](../evidence/selected/graph-confidence-qualification.json).

Tree's original version is now excluded for the supplied operation's value-contract failure. The written operation does not forbid multiplying an object by itself. Accepted before/after controls and separate reviews support that narrow decision. The official reference avoids this case, and the affected subtask is only five of 100 points; no whole-task score effect or certification of the correction is claimed. [Accepted decision](../evidence/selected/tree-original-exclusion.json).

English's original remains excluded for the final supplied grader's missing assessment-completeness validation. The versioned correction now passed four offline calls through that supplied source and the candidate, using fixed model responses and an explicit controlled rubric. A complete partial assessment remained byte-identical at valid 96; an omitted rule changed original valid 96 to candidate invalid 0. The earlier 100-point examples remain tied to the earlier grader copy. Installed-image/harness parity, effective rubric identity and real provider behavior remain unmeasured; the correction is not a certified replacement. [Original decision](../evidence/selected/english-original-exclusion.json); [accepted repair check](../evidence/selected/english-final-source-repair.json).

Schemathesis Config's complete original scoring path was already observed and has now been recovered. Reference and wrapper each completed 126 outcomes, passed 22 overall and all 15 metric checks, and received the same partial score 0.135313. The missing identity test is a confirmed repair requirement. Intentional partial credit and equal scores limit the conclusion: no wrapper gain or automatic exclusion is established, and actual submission-history selection remains unobserved. [Accepted recovery](../evidence/selected/schemathesis-full-consumer-recovery.json).

The two-file Schemathesis correction and English completeness correction are now available as [native-format patch candidates](../proposedrepairs/). Their manifests bind exact original and changed files and describe the tested scope. Neither has a newly integrated, certified replacement image.

The [recorded decisions](../evidence/selected/12-finding-decisions.json) retain the exact claims, source identities, counterexamples and accepted evidence references. Later original-version exclusions are recorded for [Wireless](../evidence/selected/wireless-original-exclusion.json), [Jagua](../evidence/selected/jagua-original-exclusion.json), and [Equivalence and Graph](../evidence/selected/eq-graph-original-exclusions.json).
