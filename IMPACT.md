# Impact on the published scores

How much do the defects move EdgeBench's published @12h means over the 51 public tasks? This page answers from the publisher's own per-task scores (`tasks/README.md`). No submission was re-scored and no model was re-run, so only effects that are a pure change of scale can be recomputed exactly. Everything else is reported as a documented bound, or as a direction whose size is open. Generated by `tools/estimate_impact.py`; data in [impact.csv](impact.csv).

- **Exact adjustments** raise every model's mean by 1.2 to 1.9 points. Almost all of this comes from Treant Forest, whose scale capped every submission at 21.02/100. The ranking is unchanged: Opus 4.8 > GPT-5.5 > GPT-5.4 > GLM-5.1 > DS-V4-Pro.
- **Documented bounds** cover the repairs with a proven or demonstrated maximum effect. Together they move a mean by at most 0.3 points down or 1.4 points up. Within these bounds, only Opus 4.8 vs GPT-5.5 can swap.
- **Open effects** are the repairs whose size cannot be known without re-scoring the original submissions. The worst-case column assumes each of them takes its full range: a downward effect removes the whole task score, and an upward effect lifts it to 100. That is a limit, not a prediction.

| Neighbouring pair | Gap after exact adjustments | Largest swing within documented bounds | Largest swing in the worst case |
| --- | ---: | ---: | ---: |
| Opus 4.8 vs GPT-5.5 | 1.2 | 1.3 | 16.9 |

| GPT-5.4 vs GLM-5.1 | 3.8 | 1.7 | 18.4 |

A pair can swap when its swing is at least its gap. The swing is the higher model's largest possible fall plus the lower model's largest possible rise. Opus 4.8 vs GPT-5.5: the gap is smaller than the documented bounds alone, so the published order of this pair is not established by the 51 public tasks. No ordering is guaranteed in the worst case. Settling it requires re-scoring the original submissions under v2.

## Exact adjustments

These repairs change only how a raw score is mapped to 0–100, so each published score can be converted directly.

| Model | Treant v1 → v2 | Borden v1 → v2 | Mean over 51 → 50 tasks |
| --- | ---: | ---: | ---: |
| Opus 4.8 | 18.0 → 86.1 | 48.4 → 44.4 | 44.14 → 45.99 |
| GPT-5.5 | 15.6 → 74.9 | 38.5 → 35.3 | 43.16 → 44.80 |
| GPT-5.4 | 13.3 → 64.2 | 8.0 → 7.3 | 34.26 → 35.65 |
| GLM-5.1 | 16.9 → 80.9 | 15.1 → 13.9 | 30.36 → 31.88 |
| DS-V4-Pro | 13.5 → 65.1 | 38.2 → 35.0 | 25.64 → 26.85 |

- **Treant Forest.** The raw score is unchanged; v2 maps it with `linear` 3,418 → 92,304 instead of `piecewise_max`. All five published scores lie below 20, the linear segment of the old scale, so each converts exactly: raw = 5,369 + s/20 × 82,820. A leaderboard value that is itself a mean of several runs converts exactly as well, because the segment is linear. The one caveat is a run between 20 and 21.02, which falls on the next segment.
- **Borden Inversion.** v1 had no rescale, so the published value is the raw score (0–109). v2 reports raw × 100/109. This is only the scale part. v2 also tells the solver the judge's physics convention, which raises honest fits (7.0 → 31.2 raw in our controls). That part needs new runs and is not included.
- **Dabic Inversion** is excluded, so it leaves the mean, which is then taken over 50 tasks (49 for Opus 4.8, which has no valid Rust Multicrate result).

## What this does not establish

- **It is not a re-scored leaderboard.** The published submissions are not public, so no historical submission was re-scored under v2.
- **It does not cover the 134-task benchmark.** The full leaderboard includes 83 unreleased tasks, which this release did not examine.
- **Neither range is an estimate.** The documented-bounds range is the largest movement we proved or demonstrated. The worst case lets every open repair take its full range.
- **Recomputed means differ slightly from the published ones** (by at most 0.06), because the per-task table is rounded to one decimal. All adjustments are applied to the recomputed means.
- **v2 scores are a different benchmark version.** These figures show how much the defects matter. They are not a substitute leaderboard.
