# The first audit

This folder holds the first audit's documents. They describe the original release and count every first-audit
fix, including fixes for claims the [second review](../FINDINGS.md) did not confirm. The repository's main
results are the [confirmed tasks](../README.md).

| File | Contents |
| --- | --- |
| [IMPACT.md](IMPACT.md) | The leaderboard estimate, not recomputed |
| [DECISIONS.md](DECISIONS.md) | The outcome for every task |
| [APPLYING-FIXES.md](APPLYING-FIXES.md) | How to build and use the fixed tasks in `repairs/` |

The case pages in [`cases/`](../cases/INDEX.md) keep each task's full record under its status line.
