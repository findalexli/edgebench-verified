# Formal results

Every task with a Lean 4 or TLA+ result. Each row links to a note that states the claim, the model and its link to the grader code, the counter-check that must fail, and the limits. All results rerun with `python3 tools/check_formal.py` (log: [RECHECK.md](RECHECK.md)).

| Task | Tool | Result | Covers | What is proved or checked | Limit |
| --- | --- | --- | --- | --- | --- |
| [SMT Solver](notes/smt_solver.md) | Lean 4 | proved | fix | On the published pattern the original checker accepts no answer at all, although the formula is satisfiable. The fixed checker never accepts a wrong answer, and accepts every correct answer written with ground keys. | A fragment with one sort, one one-argument function, let, =, not and and; not define-fun, ite or arithmetic |
| [Order Addition Permutation Optimization](notes/order_addition_permutation_optimization.md) | TLA+ | proved | fix | Under the original checksum a run always keeps its first valid submission; under the fixed one it keeps the highest-scoring valid submission. Checked over 5.4 million states, and against the real selection code on 112,944 runs. | Runs of up to four submissions and three score values |
| [Triangulation Coloring Optimization](notes/triangulation_coloring_optimization.md) | Lean 4 | proved | fix | The fixed flip rule holds exactly when the quadrilateral is strictly convex, and an accepted flip never folds the mesh. On a valid triangulation it forbids no flip the README allows. The original accepts the published folding flip. | One flip at a time; not the whole mesh |
| [Equivalence Class Divide and Conquer](notes/equivalence_class_divide_and_conquer.md) | Lean 4 | proved | fix | The original checker counts the true cost minus the last step; the fixed one counts it exactly. The two verdicts differ exactly when the cost lies between the limit and the limit plus the last step. | The per-state sizes are taken as given; that code is identical in both versions |
| [College English Exam Bank](notes/college_english_exam_bank.md) | Lean 4 | proved | fix | The fixed grader never scores an assessment that leaves out a rule, gives exactly the original total for every assessment it accepts, and never gives full marks to a rule whose row records a deduction. The proof found four gaps in the first version of this fix, which was then revised. | Text fields reduced to yes/no; deductive rules only (all 12 here) |
| [Graph Node Classification](notes/graph_node_classification.md) | Lean 4 | proved | fix | The fixed grader accepts a file exactly when every test node has one integer class, and then scores it as the original does. Keeping the best submission provably turns variance into expected gain. | Four ASCII control characters behave differently in Python; the size check is not modelled |
| [FFmpeg swscale Reimplementation](notes/ffmpeg_swscale_reimplementation.md) | Lean 4 | proved | fix | Under the fixed grader a failing or unverified timed call never raises the score, and submissions whose timed calls all verify score exactly as before. The original pays a failed call as if it succeeded. | Real arithmetic rather than IEEE doubles; image quality treated as pass or fail |
| [Schemathesis Datagen Pipeline](notes/schemathesis_datagen_pipeline.md) | Lean 4 | proved | fix | The fixed date test accepts exactly the valid web dates (real calendar date, matching weekday, valid time). Python's weekday rule equals Zeller's congruence, and agrees with Python on all 3,652,059 dates in years 1 to 9999. | The regular expression is modelled by a hand-written parser |
| [CTA Risk Budget Optimization](notes/cta_risk_budget_optimization.md) | Lean 4 | proved | fix | The fixed check is exactly the 40% test of the risk policy on yuan values, and it can only lower credit. The published position is rejected by the fixed check and accepted by the original. | The exchange-rate lookup by date is not modelled |
| [Integer Compression Codec](notes/integer_compression_codec.md) | Lean 4 | proved | fix | No submission can score above 320 raw; the fixed scale maps the starter to 0 and that maximum to 100. The regraded real submission's 160.76 and 50.08 are exact. | Timing noise is outside the model |
| [Lean Analysis Proofs](notes/lean_analysis_proofs.md) | Lean 4 | proved | fix | Two statements the agent must prove are false, refuted inside the task's own image against its own definitions. Both corrected statements are proved. | Covers the two statements, not the rest of the library |
| [Tree Block Partitioning](notes/tree_block_partitioning.md) | TLA+ | proved | fix | The original library computes v *= v wrongly; the fixed library is correct whether or not the operands are the same object. | Arithmetic modulo 4 instead of 2¹⁶ |
| [Jagua Nesting Optimization](notes/jagua_nesting_optimization.md) | Lean 4 | partly proved | fix | For axis-aligned rectangles the fixed check rejects exactly the pairs whose interiors meet, beyond its 1e-6 tolerance. | [Exchange Core Throughput](notes/exchange_core_throughput.md) | Lean 4 | partly proved | finding | The original correctness check depends only on overall money balance and final order books, so it cannot detect a fee swap or dropped messages. | The fix relies on the project's own tests, which cannot be proved here |
| [Treant Forest](notes/treant_forest.md) | Lean 4 | partly proved | numbers | Each case scores at most 2N², so a perfect submission scores exactly 2543510/121003 on the original scale; the fixed scale and every converted leaderboard value are exact. | The total 92,304 is taken as an input; the 50 case files are not available locally |
| [Borden Source Inversion](notes/borden_source_inversion.md) | Lean 4 | proved | numbers | The fixed scale and every converted leaderboard value are exact. | Only the change of scale; the physics convention is not formalizable |
| [Warehouse Forklift Routing](notes/warehouse_forklift_routing.md) | Lean 4 | proved | finding | Every valid answer totals at least 712.538, above the top reference point 395.80, so no score exceeds about 30.3.
